# Forever Heroes

Таблица персонажей WoW Forever с раскрывающимися профессиями и игровыми иконками. Для расы, чья иконка недоступна, используется портрет персонажа из оружейной.

## Список персонажей

Редактируйте `roster.json`: `region` — eu/us; `owners` — объект «владелец: список имён и фамилий». Серёже принадлежат Lailah Shemesh и Lailah Primali. Пустые списки допустимы.

## GitHub Pages и автоматическое обновление

1. В Settings → Pages → Build and deployment выберите Source: **GitHub Actions**.
2. Файл `.github/workflows/update-heroes.yml` должен быть в ветке main, которая должна быть default branch.
3. В Actions выберите **Update heroes and deploy Pages → Run workflow** для первого запуска.

После этого сбор выполняется каждый час на 17-й минуте UTC, а также при изменении списка или скрипта и по ручному запуску. Компьютер владельца не нужен. Расписание GitHub может запускаться с задержкой; в неактивных публичных репозиториях GitHub отключает расписание после 60 дней без активности — его можно включить снова во вкладке Actions.

Workflow собирает кандидат `_site/index.html`, загружает артефакт и развёртывает его через deploy-pages. В main не создаются ежечасные коммиты. На сайт загружается только готовая страница, а не исходники или кэш.

**Успех означает получение всех указанных профилей.** Любая ошибка профиля после повторных попыток останавливает сборку до публикации. Последняя успешная публикация и её время остаются на сайте. Если Allison Burgers продолжает возвращать HTTP 500, автоматическая публикация будет ждать восстановления профиля или исправления списка. Ошибка видна в логе Actions.

## Локальная сборка

Нужен Python 3.10+ без дополнительных библиотек:

```sh
python3 update.py
python3 update.py --output _site/index.html
python3 -m unittest discover -p 'test_update.py'
```

`template.html` задаёт оформление; `icons.json` хранит встроенные иконки, недостающие скрипт загружает сам. `cache.json` — исходный сохранённый снимок; он не является хранилищем состояния между облачными запусками. Последняя рабочая версия в облаке сохраняется самой службой Pages.

`python3 update.py --offline` собирает из кэша без обновления времени.
`python3 update.py --allow-partial` явно разрешает частичную выгрузку для просмотра: такой HTML помечен «Частичный снимок». Плановый workflow этот режим не использует.

При первоначальной подготовке `index.html` может содержать частичный снимок, пока не доступны все профили. Не считайте его успешным полным сбором. Рабочая страница после успешного запуска Actions хранится в Pages deployment; index.html в main не обновляется ежечасно.

Источник данных — JSON публичной оружейной Blizzard. При изменении её структуры потребуется поправить парсер. Секреты и пароль Battle.net не нужны.
