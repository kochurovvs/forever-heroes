# Forever Heroes

Таблица персонажей WoW Forever с раскрывающимися профессиями и игровыми иконками. Для расы, чья иконка недоступна, используется портрет персонажа из оружейной.

## Список персонажей

Редактируйте `roster.json`: `region` — eu/us; `owners` — объект «владелец: список имён и фамилий». Серёже принадлежат Lailah Shemesh и Lailah Primali. Пустые списки допустимы.

## GitHub Pages и автоматическое обновление

1. В Settings → Pages → Build and deployment выберите Source: **GitHub Actions**.
2. Файл `.github/workflows/update-heroes.yml` должен быть в ветке main, которая должна быть default branch.
3. В Actions выберите **Update heroes and deploy Pages → Run workflow** для первого запуска.

GitHub Actions планирует сбор каждые 15 минут, на 02-й, 17-й, 32-й и 47-й минутах каждого часа UTC. Сбор также можно запустить вручную или изменением списка героев, скрипта, шаблона, иконок или файла workflow в main. GitHub может задерживать плановые запуски. После 60 дней без активности расписание публичного репозитория можно снова включить во вкладке Actions.

Workflow собирает кандидат `_site/index.html`, загружает артефакт и развёртывает его через deploy-pages. GitHub Pages публикует готовую страницу напрямую из артефакта.

**Успех означает получение всех указанных профилей и журналов квестов.** Любая ошибка профиля после повторных попыток останавливает сборку до публикации. Последняя успешная публикация и её время остаются на сайте. Если Allison Burgers продолжает возвращать HTTP 500, автоматическая публикация будет ждать восстановления профиля или исправления списка. Ошибка видна в логе Actions.

## Локальная сборка

Нужен Python 3.10+ без дополнительных библиотек:

```sh
python3 update.py
python3 update.py --output _site/index.html
python3 -m unittest discover
```

`template.html` задаёт оформление; `icons.json` хранит встроенные иконки, недостающие скрипт загружает сам. `cache.json` — исходный сохранённый снимок; он не является хранилищем состояния между облачными запусками. Последняя рабочая версия в облаке сохраняется самой службой Pages.

`python3 update.py --offline` собирает из кэша без обновления времени.
`python3 update.py --allow-partial` явно разрешает частичную выгрузку для просмотра: такой HTML помечен «Частичный снимок». Плановый workflow этот режим не использует.

При первоначальной подготовке `index.html` может содержать частичный снимок, пока не доступны все профили. Не считайте его успешным полным сбором. Свежую версию страницы после успешного запуска Actions можно открыть по адресу GitHub Pages.

Профили берутся из оружейной Blizzard. Вкладка Dungeons использует Battle.net API. Добавьте `BLIZZARD_CLIENT_ID` и `BLIZZARD_CLIENT_SECRET` в GitHub Actions Secrets или в переменные окружения для локальной онлайн-сборки. При ручном и плановом запуске сборка заново читает активные и сданные квесты всех героев. Каталог подземелий, рекомендуемые уровни и отметки запланированных походов находятся в `dungeons/catalog.json`.
